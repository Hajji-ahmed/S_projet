Trouver le code d'un écran ou d'une fonction

Fiche pratique : retrouver un composant (frontend) ou une règle métier (backend) en moins d'une minute.

1Les raccourcis VS Code

RaccourciUsage
Ctrl+POuvrir un fichier par son nom : FraisCard
Ctrl+Shift+FChercher un texte dans tout le projet
Ctrl+TTrouver une fonction ou un composant : somme_soldes
Ctrl+Shift+OLister les fonctions du fichier ouvert
F12 / Ctrl+clicAller à la définition
Shift+F12Voir tous les endroits qui l'utilisent
Alt+←Revenir à l'endroit précédent
Dans la recherche globale, remplissez « files to include » avec frontend/** ou backend/app/** pour ignorer node_modules.

2Partir de ce que vous voyez à l'écran

  1. Un texte affiché (titre, bouton, colonne) : copiez-le et cherchez-le avec Ctrl+Shift+F. Vous arrivez sur le composant qui l'affiche.
  2. L'adresse de la page : /rapprochement correspond à frontend/app/(app)/rapprochement/page.tsx. Ses composants sont dans frontend/components/rapprochement/ (un dossier par écran).
  3. Les données affichées : dans le navigateur, ouvrez F12 puis l'onglet Réseau et relevez l'appel /api/position/.... Cherchez-le dans backend/app/api/ pour trouver la route.
  4. Le nom du module : le tableau de CLAUDE.md donne, pour chaque module, son fichier docs/decisions/*.md et ses fichiers de code.

3Le chemin d'une donnée, de l'écran à la base

Frontend : frontend/

app/(app)/<page>/page.tsxla page (= l'URL)
components/<module>/les composants de l'écran
services/*.tsappels à l'API
lib/*.tsoutils : api, format, accounts…
→HTTP
/api

Backend : backend/app/

api/*.pyroutes, sans règle métier
services/*_service.pyrègles métier et calculs
repositories/*.pyrequêtes à la base
models/*.py · schemas/*.pytables · format des données

4Où chercher quoi

Je cherche…DossierExemple
Un calcul, une règle métierbackend/app/services/position_service.py
Une route de l'APIbackend/app/api/router.py (tous les modules)
Une requête en basebackend/app/repositories/position_repository.py
Une table, une colonnebackend/app/models/et docs/modele-donnees.md
Un tableau, une carte, un boutonfrontend/components/<module>/position/GridCell.tsx
Un composant commun (Card, Modal…)frontend/components/ui/page /design-system
Le format d'un montantfrontend/lib/format.tsformatAmount(), formatNombre()
Une permission, un rôlebackend/app/core/permissions.pycopie dans lib/permissions.ts
Le pourquoi d'une décisiondocs/decisions/un fichier par module, daté
Le plus rapide : décrivez à Claude ce que vous voyez (« où est calculée la colonne DEPASSEMENT ? »). Il répond avec le fichier, la ligne exacte et un lien cliquable.
